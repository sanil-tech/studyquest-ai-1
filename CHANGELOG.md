# Changelog

All notable changes to the StudyQuest project will be documented in this file.

## [RC1] - 2026-08-02

### Added (The MVP Architecture)
- **Phase 1-2**: Initialization and KSSR/KSSM Taxonomy implementation.
- **Phase 3-4**: Resource Library and AI Content Engine built to procedurally generate KSSR aligned lessons.
- **Phase 5-7**: Assessment Engine, Mastery Engine, and Recommendation Engine created to build the core adaptive learning loop.
- **Phase 8-10**: AI Tutor (Cikgu AI) added for dynamic, mid-widget conceptual hints.
- **Phase 11-13**: Base44 Persistence established, along with full Parent Dashboard telemetry.
- **Phase 14-16**: Gamification Architecture (Adventure Map, Levels, Quests) and Retention systems established.
- **Phase 17-19**: Real User Account/Authentication systems and Parent Trust workflows implemented.
- **Phase 20-21**: Content Factory Pipeline built for mass lesson generation.
- **Phase 22-23**: Content Production Runner and Gold Standard Validation tools implemented to ensure generated lesson quality.
- **Phase 24**: End-to-End Pilot Onboarding Drill successfully completed, proving architectural integrity.

### Ready for Closed Alpha
- The system is now locked for new feature development.
- Production focus shifts entirely to Bug Triage and Curriculum Generation.
