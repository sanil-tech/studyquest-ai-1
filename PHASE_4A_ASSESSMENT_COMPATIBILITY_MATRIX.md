# PHASE 4A: ASSESSMENT COMPATIBILITY MATRIX

This document maps current repository assessment/quiz entities and modules against the Phase 3/4 Content Library & Immutable Snapshot Target Architecture.

---

## 1. ENTITY & MODULE COMPATIBILITY MATRIX

| Entity / Module | Current Schema & Usage | Content Library Compatibility | Snapshot Compatibility | Verdict & Action |
|---|---|---|---|---|
| `QuestionBank` | Database Entity (`QuestionBank.jsonc`) | **100% Compatible** (`topic_id`, `sp_code`, `status`, `review_status`, `created_source`, `approved_by`) | **100% Compatible** (Copied into `LessonVersion` snapshot by `assembleLessonFromApprovedAssets`) | **CANONICAL**. Primary quiz item asset entity. No schema change needed. |
| `QuestionOption` | Database Entity (`QuestionOption.jsonc`) | **100% Compatible** (Child of `QuestionBank` via `question_id`) | **100% Compatible** (Child options preserved) | **CANONICAL**. Option entity for structured MCQ choices. |
| `Assessment` | Database Entity (`Assessment.jsonc`) | **100% Compatible** (`topic_id`, `sp_code`, `passing_score`, `reward_xp`, `reward_coin`) | **100% Compatible** (Linked via `lesson_version_id`) | **CANONICAL**. Assessment container entity. |
| `QuizAttempt` | Database Entity (`QuizAttempt.jsonc`) | **Historical Log** (Bound to `student_id`, `assessment_id`, `submission_hash`) | **Immutable** (Does not change if Content Library changes) | **CANONICAL**. Authoritative student attempt history & reward record. |
| `submitAssessment` | Server Function (`submitAssessment/entry.ts`) | **Server-Authoritative** (Evaluates answers, SHA-256 idempotency, anti-farming) | **Snapshot Bound** (Evaluates against server DB) | **CANONICAL**. Server scoring & reward engine. |
| `getLearningPackage` | Server Function (`getLearningPackage/entry.ts`) | **Sanitized Payload** (Omits answer keys from student client payload) | **Published Only** (Reads `Lesson.published_version_id`) | **CANONICAL**. Student runtime API. |
| `QuizRunner.jsx` | React Component (`QuizRunner.jsx`) | **Client Presentation** (Sends `answers[]` to `submitAssessment`) | **Sanitized** (Contains NO client scoring or answer keys) | **CANONICAL**. Primary student quiz runner interface. |
| `QuizResult.jsx` | React Component (`QuizResult.jsx`) | **Client Presentation** (Displays server-returned score & XP/coins) | **Read-Only** (Renders `submitAssessment` response) | **CANONICAL**. Primary quiz result display card. |
| `assessmentEngine.js` | Legacy Helper (`assessmentEngine.js`) | **Synthetic Prototype** (Generates client-side questions with embedded answers) | **Non-Snapshot** (Independent of DB) | **ACTIVE LEGACY**. Retained for prototype fallback; not part of canonical runtime. |
| `diagnosticAssessmentService.js` | Diagnostic Helper (`diagnosticAssessmentService.js`) | **Diagnostic Engine** (Generates initial diagnostic placement tests) | **Independent** | **ACTIVE COMPATIBILITY**. Retained for student diagnostic placement flow. |

---

## 2. KEY ARCHITECTURAL INVARIANTS CONFIRMED

1. **Zero Client Answer Key Exposure**: Student payload generated by `getLearningPackage` omits `correct_answer` and `is_correct`.
2. **Server-Authoritative Evaluation**: `submitAssessment` performs all grading, XP/coin calculations, and idempotency hashing server-side.
3. **Snapshot Isolation**: `assembleLessonFromApprovedAssets` copies approved `QuestionBank` assets into `lesson_version_id` snapshot records. Modifications to library questions later do not alter published lesson versions.
